# Niveau 01 - Premier Programme, Printf et Commentaires

## 🎯 Objectif
Apprendre à afficher du texte sur la console avec des sauts de ligne et utiliser les différents styles de commentaires du langage C.

## 📝 Énoncé
Écrivez un programme `main.c` qui :
1. Comporte un commentaire de documentation au-dessus de `main` avec les balises `/// <summary>`.
2. Affiche sur la console le message de bienvenue suivant sur 3 lignes distinctes :
   ```text
   Bienvenue en Informatique C !
   TD PRG1000 & 1001
   Pret pour progresser.
   ```
3. Utilise un commentaire sur une seule ligne (`//`) pour expliquer une instruction.
4. Utilise un commentaire multi-lignes (`/* ... */`) pour expliquer le rôle de `return 0;`.
