# Niveau 07 - Permutation (Swap) et Tri de 3 Valeurs

## 🎯 Objectif
Apprendre à échanger le contenu de deux variables à l'aide d'une variable temporaire et ordonner 3 valeurs croissantes sans tableau.

## 📝 Énoncé
Dans le TP1 (Exercice 2), un voyageur présente un bagage dont on mesure les 3 dimensions (longueur, largeur, hauteur) en cm.
Le bagage est admis en cabine s'il ne dépasse pas le gabarit $55 \times 35 \times 25$ cm, quel que soit le sens dans lequel il est mesuré.

Écrivez un programme qui :
1. Demande les 3 dimensions réelles $D_1, D_2, D_3$ (ex: 30, 50, 20 cm).
2. Ordonne les 3 valeurs dans l'ordre croissant $D_1 \le D_2 \le D_3$ en utilisant 3 comparaisons `if` et une variable temporaire `tmp`.
3. Affiche les dimensions triées.
4. Conclut immédiatement avec un test simple si le bagage est `VALIDE` ou `NON VALIDE` pour la cabine.
